# Eval design

## LLM

Смотри не MMLU. Смотри то, что ломает агента: JSON-маршрут, следование ограничению длины, верность короткому контексту, отказ обойти песочницу, латентность на 8 ГБ.

## Система

- Task Success Rate по золотым кейсам.
- Handoff accuracy (нужные узлы были).
- Loop rate (упёрлись в max_steps).
- Tool error rate.
- Critic score и расхождение critic vs автоматическая проверка.

## Непрерывность

Ночной прогон пишет Prometheus gauge. Алерт — на падение TSR и рост петель. Langfuse/файловые трейсы — чтобы разобрать один плохой кейс, не средний балл.
