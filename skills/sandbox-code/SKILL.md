# Sandbox code

## Можно

- Арифметика, циклы, списки, строковые преобразования.
- Модули, которые уже инжектит рантайм песочницы: `math`, `statistics`, `json` (только в local-restricted allowlist; в Docker sandbox — см. сервер).
- Кладёшь ответ в `result`.

## Нельзя

- Любой `import`, `open`, dunder, сеть, subprocess, чтение env.
- Бесконечные циклы. Считай, что timeout 8с — это часть ответа.

## Если инструмент отказал

Не пытайся «выполнить в уме сложный код». Верни ошибку critic. Для простого выражения используй `calculate`.
