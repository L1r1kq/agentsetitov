# Report writing

Пиши markdown с этими заголовками, без новых:

1. `Справочный отчёт (это не диагноз и не замена врачу)`
2. `Структура жалобы` — маркеры из текста, пробелы отдельно
3. `Что есть в локальном справочнике` — только по findings, с именами файлов
4. `Красные флаги` — сработали / не сработали по тексту, без успокоения если сработали
5. `Чего нельзя решить по этому сообщению`
6. `Практический следующий шаг` — очный осмотр / неотложка / «если усилится — к врачу». Без названий таблеток и доз.

Запрещённые подстроки: `у вас`, `диагноз:`, `это точно`, `примите`, `мг`.
