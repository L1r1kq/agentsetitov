# Medical reference

1. Вызови `knowledge_search` по жалобе.
2. Если в тексте есть грудь / одышка / кровь / сознание / паралич / судорога — явно читай `knowledge/RED_FLAGS.md`.
3. Каждый finding: одна мысль + файл (`fever_cough.md`).
4. Нет попадания → unknown, не энциклопедия из параметров модели.
5. Нельзя превращать название карточки в диагноз человека.
