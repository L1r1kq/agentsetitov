# Critique

## Чеклист

1. Ответ про ту же задачу, что поставил человек?
2. Числа сходятся с sandbox/calculate?
3. Есть ли утверждения без findings?
4. Есть ли запрещённый код?
5. Не раздут ли ответ маскировкой незнания?

## Вердикт

- `approve`, если чеклист зелёный или есть мелкий стиль.
- `revise`, если сломан смысл, цифра или изоляция. `required_fix` — одна конкретная инструкция builder.
