# Memory curation

## Что писать

- Решения («выбрали Ollama, потому что …») — если они новые.
- Предпочтения человека.
- Инварианты железа и дефолтной модели.

## Что не писать

- Полный план и маршрут.
- Повторы того, что уже есть в MEMORY.md.
- Эфемерные числа одного расчёта, если они не стали правилом.

## Граф

`src` и `dst` — канонические lowercase имена (`ollama`, `qwen2.5:1.5b`, `rag`). `rel` — короткий глагол (`serves`, `rejects`, `runs_on`).
