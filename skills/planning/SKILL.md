# Planning

## Когда применять

Любая новая задача, любой рестарт после смены цели.

## Процедура

1. Переформулируй цель одним предложением.
2. Перечисли неизвестные. Если неизвестное закрывается памятью — шаг researcher. Если вычислением/кодом — builder.
3. Сделай 3–6 шагов. У каждого шаг есть артефакт: список фактов, число, код, вердикт.
4. Не планируй «написать красиво». Это не шаг.

## Антипримеры

- «Исследовать тему и ответить» — слишком крупно.
- План из 12 шагов на 1.5B модель — не исполнится за max_steps.
