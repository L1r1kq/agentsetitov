# Planning

Типовой план на 4 шага:

1. Разобрать жалобу на поля (скилл symptom-intake).
2. Найти карточки knowledge_search.
3. Собрать справочный отчёт (report-writing).
4. Проверить антидиагноз и красные флаги.

Не планируй лабораторные интерпретации и схемы лечения.
