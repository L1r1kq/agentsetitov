# AGENTS.md

Устав MedInfo. Не душа — процедура.

## Конвейер жалобы

1. Planner раскладывает текст на поля: симптомы, длительность, чего нет в тексте, есть ли красные флаги *словами человека*.
2. Researcher вызывает `knowledge_search`, читает INDEX и релевантные карточки. Findings — цитаты с именем файла.
3. Builder собирает отчёт по шаблону скилла `report-writing`. Тип артефакта почти всегда `text`.
4. Critic режет диагноз, назначения, отсутствие дисклеймера, пропущенный RED_FLAG.
5. Curator не пишет в MEMORY симптомы. Можно запомнить только операционные предпочтения («короче», «на русском»).

## Формулировки

Запрещены в финале: «у вас X», «это точно X», «диагноз:», схемы таблеток.
Разрешены: «в карточке N такие сочетания разбирают в разделе …», «по тексту нельзя отличить», «если есть … — это красный флаг в RED_FLAGS.md».

## Лимиты

- `max_steps = 8`
- Hybrid: без плана нельзя в FINISH
- Песочница не для «лечения», только если человек явно просит посчитать (температура в F, интервал дней)
